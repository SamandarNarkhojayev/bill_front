# Biliardo — канал обновлений

Здесь публикуются установщики приложения **Biliardo** — программы для
автоматизации бильярдного клуба (столы, бар, отчёты, управление светом).

Исходный код закрыт и в этом репозитории не хранится.

## Скачать

Последняя версия — на вкладке [Releases](../../releases/latest).

## Приложение

Сайт и условия: [biliardo.kz](https://biliardo.kz)

## Обновления

Установленное приложение обновляется само. Этот репозиторий используется
как резервный канал обновлений; основной канал — сервер biliardo.kz.
